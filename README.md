### Sentiment Analysis and Recommendation System on Amazon Reviews

This repository contains the project for the course Data Mining Techniques at the National and Kapodistrian University of Athens (NKUA).

The project uses the Amazon Reviews 2023 dataset (McAuley Lab), focusing on five product categories.

The project is divided into four main parts:

- Exploratory data analysis
- Sentiment analysis
- Product clustering using k-means
- Recommendation system using collaborative, content-based and hybrid filtering
